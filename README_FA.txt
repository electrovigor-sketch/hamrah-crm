همراه کسب‌وکار — CRM محلی PWA
================================

امکانات:
- مدیریت مشتریان، سفارش‌ها، پیگیری‌ها و یادداشت‌ها
- فیلتر سه کسب‌وکار: الکترو ویگور، امید باتری، نیل بیوتی
- رابط فارسی و راست‌چین
- نمایش تاریخ شمسی و ورود تاریخ‌های پیگیری/سفارش به صورت شمسی
- ذخیره اطلاعات در مرورگر دستگاه با localStorage
- خروجی پشتیبان JSON و بازیابی پشتیبان
- خروجی CSV
- پوسته PWA و Service Worker برای آفلاین پس از بارگذاری اولیه

مهم:
1) این نسخه اطلاعات را در مرورگر همین دستگاه نگه می‌دارد و همگام‌سازی ابری ندارد.
2) اگر داده‌های مرورگر پاک شوند ممکن است اطلاعات حذف شوند؛ مرتب JSON پشتیبان بگیرید.
3) برای نصب PWA و فعال شدن Service Worker، برنامه را روی HTTPS منتشر کنید.
4) برای GitHub Pages: محتوای ZIP را در ریشه یک مخزن GitHub بارگذاری کنید و از Settings > Pages، انتشار از شاخه اصلی و پوشه ریشه را فعال کنید. پس از انتشار لینک HTTPS را در Chrome اندروید باز کنید و از منوی سه‌نقطه «افزودن به صفحه اصلی» را بزنید.
5) این نسخه اولیه است؛ قبل از ورود اطلاعات حساس یا استفاده روزمره، با داده آزمایشی تست کنید و پشتیبان بگیرید.

تاریخ شمسی:
- تبدیل تاریخ جلالی/میلادی با الگوریتم معتبر جلالی انجام می‌شود؛ تاریخ‌های ورودی به صورت شمسی و ذخیره داخلی به صورت میلادی استاندارد نگه‌داری می‌شوند.
- همچنان پیش از ورود اطلاعات مهم، چند تاریخ نمونه و پشتیبان‌گیری/بازیابی را آزمایش کنید.
